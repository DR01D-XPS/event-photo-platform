# picflow

Одностраничное локальное приложение для загрузки изображений, админской модерации и автоматического показа одобренных изображений в режиме слайд-шоу.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Режимы

- Пользовательский режим: откройте главную страницу, введите обычное имя, выберите изображение и нажмите «Отправить».
- Админ-режим: введите в поле имени значение из `ADMIN_CODE` и дождитесь переключения интерфейса.
- Слайд-шоу: введите в поле имени значение из `SHOWROOM_CODE`.

По умолчанию используются коды:

- `YOUR_ADMIN_CODE` для админки.
- `YOUR_SHOWROOM_CODE` для слайд-шоу.

Коды не используются во фронтенд-коде напрямую: поле имени отправляется на `/api/mode`, а сервер возвращает режим и временный подписанный токен для админских действий.

## Переменные окружения

Создайте `.env.local` по примеру `.env.example`:

```bash
ADMIN_CODE=YOUR_ADMIN_CODE
SHOWROOM_CODE=YOUR_SHOWROOM_CODE
ADMIN_ACTION_SECRET=change-this-long-random-secret
MAX_UPLOAD_MB=10
UPLOAD_DELAY_SECONDS=30
UPLOAD_HOURLY_LIMIT=8
```

- `ADMIN_CODE` — кодовое слово для входа в админский режим.
- `SHOWROOM_CODE` — кодовое слово для входа в режим слайд-шоу.
- `ADMIN_ACTION_SECRET` — секрет для подписи токенов админских действий.
- `MAX_UPLOAD_MB` — максимальный размер файла.
- `UPLOAD_DELAY_SECONDS` — минимальная задержка между загрузками для одной пары IP + имя.
- `UPLOAD_HOURLY_LIMIT` — максимальное количество загрузок за час для одной пары IP + имя.

Чтобы поменять кодовые слова, измените `ADMIN_CODE` и `SHOWROOM_CODE` в `.env.local`, затем перезапустите dev-сервер.

## Хранение

- Метаданные изображений: `data/images.json`.
- Состояние простого rate limit: `data/rate-limit.json`.
- Изображения на модерации: `uploads/pending`.
- Одобренные изображения: `uploads/approved`.

Оригинальное имя файла сохраняется только в метаданных. Реальный файл получает безопасное уникальное имя.

## Безопасность

Приложение проверяет:

- наличие имени и файла;
- длину имени;
- honeypot-поле;
- расширение файла;
- MIME type;
- базовую файловую сигнатуру изображения;
- размер файла;
- частоту загрузок;
- подписанный сервером токен для чтения очереди и модерации.

Это локальная простая архитектура без полноценной авторизации, но серверная проверка уже отделена так, чтобы позже заменить кодовые слова на нормальный логин.
